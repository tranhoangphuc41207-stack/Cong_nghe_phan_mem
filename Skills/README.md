# Skills

Các file hướng dẫn (skill) cho hệ thống AR-IMMS (backend, web, Agent). Mỗi thư mục là một skill, nội dung trong `SKILL.md`.

- `backend-overview/` - tổng quan, cách chạy, database, module, quy ước code
- `auth-and-roles/` - JWT, API key, phân quyền theo vai trò
- `telemetry-and-alerts/` - nhận telemetry, phát hiện Offline, cảnh báo realtime
- `audit-log/` - ghi nhật ký hoạt động tự động
- `web-frontend/` - web Next.js: gọi API, đăng nhập, Socket.IO, trang mock
- `collector-agent/` - Agent thu số liệu và gửi bù
